# 油链天工 · Tiangong Petro Atlas

石油勘探开发智能化可能性地图 —— 《可视化导论》课程大作业。

纯前端静态站点（无后端、无构建、断网可跑）：双击 `index.html` 即可离线运行。

## 内容

- **13 个作业环节 · 61 个场景全覆盖**，每个场景配套一个完整智能化案例（专业背景 / 案例流程 / 可运行示范），含框架自带示范共 **62 个案例**
- 每个案例的专业背景配手绘 SVG 原理图；示范页为真实算法在浏览器现场运行（现场训练、k-NN、变点检测、CUSUM、聚类、代理模型寻优……），固定随机种子可复现
- 四个时序类示范带「实时回放」：像调度监控屏一样逐点流入数据、告警实时点亮
- 「＋ 添加案例」上传通道与原框架完全兼容：其他同学的案例包可不经修改直接导入

## 使用

| 入口 | 说明 |
|---|---|
| 首页 | 两条检索路径：按 13 环节链条 / 按五类 AI 方法反查 |
| 作业链 | 完整环节 → 场景下钻 |
| 案例库 | 62 个案例注册表与逐项校验结果 |
| 接入指南 | 案例包契约与三步接入文档 |
