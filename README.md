# 油链天工 · Tiangong Petro Atlas

石油勘探开发智能化可能性地图 —— 《可视化导论》课程大作业。

纯前端静态网站，算法计算、模型教学实验与可视化均在浏览器内完成，无业务后端。

## 内容

- 13个作业环节、84个应用场景、94个注册案例，其中93个为自建案例，1个为框架自带案例。
- 钻井包含28个场景、33个自建案例，其余12个环节各有5个自建案例。
- 首页保留左侧介绍、右侧三维展示的布局，采用石油全流程交互沙盘。
- 13个环节配置对应三维概念场景；其余12类新增展厅各含3个镜头，并支持过程进度、暂停和巡览。
- 案例包含专业背景、案例流程和可运行演示，使用图解与交互图表解释石油问题、算法步骤和计算结果。
- 全部94个注册案例提供具体算法说明，区分特征输入、学习与求解、推理与决策、验证结果。
- 演示支持原参数联动和方案A/B对照，部分案例提供浏览器内训练、基线比较及分组验证。
- 支持案例检索、方法筛选、收藏、明暗主题及原规范案例包导入（文件、文件夹、ZIP、RAR、7z）。

数据、概念场景与简化模型用于可视化教学，不代表现场验证效果或生产控制能力。

## 使用

通过静态HTTP服务器访问本目录，以便浏览器正常加载模块和数据。独立教学演示另见 `showcase/d26/`、`showcase/d27/`、`showcase/d28/`。

在线访问：[油链天工](https://xiao1783.github.io/tiangong-petro-atlas/)。

## 本次更新

添加案例支持直接选择或拖入 ZIP、RAR（RAR4/RAR5）、7z，无需手动解压。自动识别外层目录，并保留演示脚本、样式和图片，沿用清单校验、示范预览与浏览器存储。解压组件随网站提供，RAR/7z 按需在后台解压。每包一个案例，解压前后均限 6 MB；暂不支持加密或分卷包。
