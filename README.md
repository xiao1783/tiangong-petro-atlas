# 油链天工 · Tiangong Petro Atlas

石油勘探开发智能化可能性地图 —— 《可视化导论》课程大作业。

纯前端静态网站，算法计算、模型教学实验与可视化均在浏览器内完成，无业务后端。

## 内容

- 13 个作业环节、84 个应用场景、90 个已接入案例。
- 案例包含专业背景、案例流程、可运行演示，使用 SVG 图表解释石油概念、算法步骤与计算结果。
- 钻井重点案例：固控分离优化、随钻遥测延迟补偿、钻头更换时机优化。
- 三个重点案例提供浏览器内模型学习、独立组验证、正常条件 / 少量样本 / 工况偏移对比。
- 支持案例检索、方法筛选、明暗主题及案例包导入。

数据与简化模型用于可视化教学，不代表现场验证效果或生产控制能力。

## 使用

打开 `index.html`，或通过静态文件服务器访问。三个重点案例的独立演示位于 `showcase/d26/`、`showcase/d27/`、`showcase/d28/`。

在线访问：[油链天工](https://xiao1783.github.io/tiangong-petro-atlas/)。
